📁 محتويات المجلد
─────────────────
  index.html      → واجهة المتجر التي يراها الزوار (الصفحة الرئيسية)
  admin.html      → لوحة التحكم (محمية بكلمة سر)
  css/style.css   → ملف التصميم
  js/data.js      → قاعدة بيانات المتجر (المنتجات + الأقسام + الإعدادات)
  js/common.js    → أدوات مشتركة (لا تعدّله)
  js/store.js     → منطق واجهة المتجر (لا تعدّله)
  js/admin.js     → منطق لوحة التحكم (لا تعدّله)

🔑 أول خطوة: الدخول للوحة التحكم
─────────────────────────────────
  1) افتح admin.html
  2) كلمة السر الافتراضية: admin123
  3) غيّرها فوراً من: الإعدادات ← الأمان ← تغيير كلمة السر

⚠️ أهم إعداد على الإطلاق: رقم واتساب
─────────────────────────────────────
  الإعدادات ← واتساب ← «رقم واتساب مع رمز الدولة»
  اكتب رقمك بدون + وبدون 0 في البداية:
    المغرب مثلاً: 212 + رقمك بدون الصفر  →  212612345678
  حتى يعمل زر «اطلب عبر واتساب» وتريك الطلبات على رقمك.
  (الرقم الافتراضي 212600000000 مجرد مثال — يجب تغييره!)

🚀 النشر على GitHub Pages (حل مشكلة «لم يتم العثور على الملف»)
──────────────────────────────────────────────────────────────
  رسالة الخطأ 404 تعني أن index.html غير موجود في الجذر.
  اتبع هذه الخطوات بالضبط:

  1) ادخل إلى مستودعك على github.com
  2) اضغط Add file ← Upload files
  3) ⚠️ الأهم: افتح مجلد «mutjari-store» على جهازك، ثم
     اسحب «محتوياته» (index.html و admin.html ومجلدَي
     css و js) إلى صفحة الرفع — وليس مجلد المتجر نفسه!
     ❌ خطأ:  your-repo/mutjari-store/index.html
     ✅ صحيح: your-repo/index.html
  4) اضغط Commit changes وانتظر انتهاء الرفع
  5) من Settings ← Pages:
       Source = Deploy from a branch
       Branch = main  و  Folder = / (root)   ← لا تختر /docs
     ثم Save
  6) انتظر دقيقة إلى دقيقتين ثم حدّث الصفحة
  7) افتح  https://اسم-حسابك.github.io/اسم-المستودع/

  ملاحظات مهمة:
  • أسماء الملفات حساسة لحالة الأحرف: يجب أن يكون
    index.html بحروف صغيرة بالضبط (وليس Index.html).
  • إذا كان مستودعك فارغاً قبل الرفع فلا مشكلة — الرفع أعلاه يكفي.
  • لاحقاً إن أردت رابطاً أقصر أنشئ مستودعاً باسم:
    اسم-حسابك.github.io  → سيصبح الموقع:
    https://اسم-حسابك.github.io/

✏️ كيف أعدّل المنتجات؟
────────────────────────
  كل شيء من admin.html بدون لمس أي كود:
  • إضافة/تعديل/حذف منتج، رفع صور متعددة، تغيير الصورة
    الرئيسية، إضافة مراجعات العملاء…
  • إنشاء الأقسام وتعديل أسمائها وحذفها.
  • تغيير اسم المتجر، الشعار، البانر، العملة، النصوص،
    ورقم واتساب — كلها من الإعدادات.

📡 كيف تصل تعديلاتي إلى «جميع» الزوار؟ (مهم)
──────────────────────────────────────────────
  الموقع ملفات ثابتة، لذلك:
  • عند تعديلك في لوحة التحكم تُحفظ التغييرات فوراً في
    متصفحك (نسخة معاينة) — تراها أنت فقط.
  • لنشرها للجميع:
     1) اضغط «⬇️ تصدير data.js» أعلى لوحة التحكم
     2) سينزل ملف data.js إلى جهازك
     3) على GitHub: ارفعه إلى مجلد js مستبدلاً القديم
        (Add file ← Upload files ← افتح مجلد js واسحب الملف)
     4) بعد دقيقة يرى الجميع التعديلات. انتهى!
  • زر «معاينة المتجر» يفتح لك الموقع بشاشة المتصفح الحالية.
  • لبدء متجرك الحقيقي: الإعدادات ← «تفريغ المتجر» يحذف
    المنتجات التجريبية، ثم أضف منتجاتك.

🖼️ نصائح للصور
───────────────
  • يتم ضغط الصور المرفوعة تلقائياً (تصغير لـ1000 بكسل).
  • التخزين المحلي في المتصفح ~5 ميغا؛ عند امتلائه ستظهر
    رسالة — في هذه الحالة احذف منتجات أو صور قديمة.
  • النسخة الاحتياطية (JSON) من الإعدادات تنقل كل بياناتك
    إلى جهاز آخر: صدّرها من الجهاز القديم واستوردها في الجديد.

🔒 ملاحظة أمنية
────────────────
  لوحة التحكم محمية بكلمة سر ولا تظهر للزوار إلا من يعرف
  عنوانها. لطبقة إضافية: أعد تسمية admin.html إلى اسم سر
  تعرفه أنت فقط (مثلاً: my-secret-panel.html) — لا يؤثر
  ذلك على أي شيء آخر.
  • إذا نسيت كلمة السر: افتح js/data.js وابحث عن
    passwordHash واستبدل قيمتها بهذا السطر:
    "passwordHash": "240be518fabd2724ddb6f04eeb1da5967448d7e831c08c8fa822809f74c720a9"
    ثم ارفع الملف — تعود كلمة السر إلى: admin123

🌐 استضافة بديلة أسهل (اختياري)
─────────────────────────────────
  • Netlify Drop: افتح app.netlify.com/drop واسحب مجلد
    الموقع كاملاً — ينشر فوراً بدون حساب معقّد.
  • أي استضافة ثابتة أخرى (Vercel, Cloudflare Pages…)
    تعمل بنفس الطريقة: ارفع الملفات كما هي.

✅ قائمة تحقق سريعة قبل الإطلاق
────────────────────────────────
  □ غيّرت رقم واتساب من الإعدادات
  □ غيّرت كلمة السر من admin123
  □ عدّلت اسم المتجر والشعار
  □ حذفت المنتجات التجريبية وأضفت منتجاتك
  □ صدّرت data.js ورفعته إلى مجلد js على الاستضافة
  □ جرّبت الطلب على منتج من هاتفك وتأكدت وصول الرسالة
